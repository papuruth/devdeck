# Changelog

All notable changes to DevDeck are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.1.0] - 2026-05-07

### Added

#### New Tool
- **API Request Builder** (`/api-builder`) — construct and send HTTP requests (GET, POST, PUT, DELETE, PATCH) with custom headers and body, view formatted JSON responses and status codes

#### New Pages
- **Blog** (`/blog`) — developer guides and tutorials for tools available in the app
- **Blog Post** (`/blog/[slug]`) — individual guide pages with per-post SEO metadata and canonical URLs

#### SEO & Structured Data
- JSON-LD `WebApplication` schema added to all 23 tool pages via a shared `ToolJsonLd` server component
- Dynamic `sitemap.ts` route handler — auto-generates `/sitemap.xml` covering all tools and blog pages
- Dynamic `robots.ts` route handler — serves `/robots.txt` pointing to the generated sitemap
- Per-page `alternates.canonical` metadata on home, blog index, and blog post pages

#### Developer Experience
- **Bundle analyzer** — `yarn analyze` script wraps the production build with `@next/bundle-analyzer`; opens a visual treemap of chunk sizes
- **Navigation progress bar** — `NavigationProgress` component wires NProgress to App Router pathname changes via `usePathname` + click delegation (no `router.events` dependency)
- **URL centralization** — all references to the production URL now source from `GLOBAL_CONSTANTS.BASE_URL` in `src/utils/globalConstants.tsx`; zero hardcoded duplicate declarations

### Changed

#### Framework Migration (CRA → Next.js 15 App Router)
- Replaced Create React App + craco build with Next.js 15 (`next dev`, `next build`, `next start`)
- Migrated all pages to the App Router (`src/app/`) with Server Components for metadata and Client Components for interactivity
- Routing changed from React Router v5 to Next.js file-system routing; `Link` from `next/link` replaces `react-router-dom`
- Global layout moved to `src/app/layout.tsx` (root Server Component wrapping all providers)

#### TypeScript Migration
- Codebase converted from JavaScript (`.js`/`.jsx`) to TypeScript (`.ts`/`.tsx`) throughout
- Strict `tsconfig.json` with path aliases matching webpack resolver aliases (`components`, `views`, `utils`, `styles`, `routes`, `localization`, `assets`, `services`, `context`, `data`, `lib`, `store`, `types`)
- All dependencies and devDependencies updated to their `@types/*` equivalents

#### Tech Stack Updates
- React 17 → React 18.3
- MUI v5 (peer-dep aligned) — engine swapped to `@mui/styled-engine-sc` (Styled Components) via webpack alias
- Styled Components 5 → 6 with Next.js SSR registry (`StyledComponentsRegistry`)
- Redux state hydration wrapped in `ReduxProvider` client component

#### Metadata & SEO
- `layout.tsx` exports `metadata` and `viewport` objects (Next.js 15 Metadata API) replacing `react-helmet`
- `metadataBase` set to `GLOBAL_CONSTANTS.BASE_URL` so relative OG image paths resolve correctly
- Each tool page exports its own `metadata` (title, description, keywords) derived from `SEO_META`

### Removed

- Create React App (`react-scripts`) and craco — replaced by Next.js
- `react-router-dom`, `connected-react-router`, `history` — replaced by Next.js file-system routing
- `react-helmet` — replaced by Next.js Metadata API
- `babel.config.js`, `jsconfig.json` — superseded by `tsconfig.json` and Next.js compiler
- `public/index.html`, `public/manifest.webmanifest` — regenerated by Next.js PWA plugin (`@ducanh2912/next-pwa`)
- `public/sitemap.xml`, `public/robots.txt` — replaced by dynamic route handlers (`src/app/sitemap.ts`, `src/app/robots.ts`)
- `react-snap` and all snapshot-related scripts

## [2.0.0] - 2026-04-27

### Added

#### New Tools
- **Regex Tester** — live pattern matching with flag toggles (g, i, m, s), 9 built-in presets (Email, URL, IPv4, UUID, JWT, and more), match highlighting, and capture group detail
- **JSON Viewer / Editor** — interactive tree view with inline add/edit/delete, search/filter, expand-all/collapse-all, and load JSON from a remote URL
- **Password Strength Meter** — real-time analysis using zxcvbn: strength score, estimated crack time, and character-type breakdown
- **YAML ↔ JSON Converter** — bidirectional conversion between YAML and JSON with live error feedback

#### New UX Features
- **Command Palette** — keyboard-accessible (`⌘K` / `Ctrl+K`) launcher to search tools, recent items, and actions from anywhere in the app
- **Smart Input** — paste any raw data (JSON, JWT, URL, timestamp…) and the app auto-detects the right tool to open
- **Tool Chaining** — send output from one tool directly into another via the "Send To" button (e.g. Password Generator → Hash Generator)
- **Shareable URLs** — Regex Tester and other tools encode their state into the URL so you can share a pre-loaded view
- **Input History** — per-tool history dropdown lets you recall recent inputs without re-typing
- **Update Banner** — in-app notification when a new version of the PWA is available, with a one-click reload

#### Developer Experience
- **Full i18n / Localization** — every visible UI string in all tools is now sourced from `localization/languages/english.js`, making the app translation-ready
- **Google Tag Manager** — analytics integration for usage tracking

### Changed

- **QR Generator** — fully redesigned with a two-panel layout; added foreground/background color pickers, size slider, optional logo overlay (drop zone), and SVG export alongside PNG
- **Image Resizer / Cropper** — rebuilt with `react-image-crop`; supports scale, rotation, free/locked aspect ratio, live crop-dimension readout, and direct canvas download
- **URL Shortener** — replaced Redux + sagas state management with local React state; removed `URLShortnerActions`, `URLShortnerReducer`, and `URLShortnerSagas`
- **Base64 Image** — refactored encoder/decoder into dedicated components (`EncodeBase64`, `DecodeBase64`) with cleaner separation of concerns
- **Global layout** — sidebar and header updated to surface the Command Palette trigger and Smart Input entry point
- **Redux store** — root reducer and root sagas slimmed down after URL Shortener migration off Redux

### Fixed

- Corrected indentation and formatting in `index.html`
- Fixed layout styling regressions in several components
- Fixed Number Formatter display and styling issues
- Fixed responsiveness issues across panel-based layouts

### Removed

- `URLShortnerActions.js`, `URLShortnerReducer.js`, `URLShortnerSagas.js` — superseded by local state
